# Отчёт о приёмочных испытаниях

Дата прогона: 17.10.2026.
Команда: `node tests/acceptance.mjs`.
Среда: Node.js 24.22.0, Windows, отдельный экземпляр приложения на временной базе (SRK_DATA_DIR), порт выделяется случайно.

Результат: **пройдено 60 проверок, провалено 0**.

Тест поднимает чистое приложение, создаёт поставщика, товар с тремя вариантами, закупку, приёмку, расходы, продажи, возвраты, проверяет права трёх ролей и отчёты, после чего останавливает сервер.

## Проверка интерфейса

Дополнительно интерфейс проверялся в headless-браузере (Microsoft Edge, CDP) на рабочем экземпляре приложения:

- вход владельцем и открытие оболочки;
- отображение всех разделов: главная, товары, закупки, приёмка, склад, продажи, возвраты, отчёты, сотрудники, настройки;
- карточки товара, закупки, приёмки и продажи без ошибок;
- создание закупки через форму с вложенным выбором товара;
- проведение продажи через корзину;
- оформление возврата из карточки продажи;
- отсутствие JS-исключений и ошибок консоли в этих сценариях.
