# Демо-приложение для Android

Отдельное приложение `Stockroom Kids Демо` показывает внешний вид и функционал системы без сервера, интернета и входа по паролю.

## Файлы

| Что | Где |
| --- | --- |
| Готовый APK | `mobile-demo/apk/stockroom-kids-demo-1.0.apk` |
| Отладочный APK | `mobile-demo/apk/stockroom-kids-demo-1.0-debug.apk` |
| Исходники интерфейса | `mobile-demo/www` |
| Локальные данные и эмулятор API | `demo/demo.js` |
| Сборка демо-интерфейса | `scripts/build-demo.ps1` |
| Android-проект | `mobile-demo/android` |

Идентификатор приложения — `ru.stockroomkids.demo`, поэтому демо ставится рядом с рабочим приложением и не конфликтует с ним.

## Установка

1. Передайте `stockroom-kids-demo-1.0.apk` на телефон.
2. Откройте файл и разрешите установку из этого источника.
3. Запустите «Stockroom Kids Демо» — сразу откроется главная панель, без экрана входа.

## Что внутри

Данные подготовлены как в реальном магазине: 6 моделей детских товаров с размерами и цветами, три закупки в юанях (получена, частично получена, заказана), приёмки с недостачей, продажи за неделю, возврат, списание, инвентаризация, история цен, сотрудники и журнал действий.

Работает без сервера и интернета:

- каталог, поиск и карточки товаров с вариантами и ценами;
- закупки, оплаты, расходы, статусы и история;
- приёмка с количеством и недостачами, проведение приёмки;
- склад: остатки, движения, корректировки, инвентаризация;
- продажи: корзина, проверка остатка, проведение, валютная прибыль;
- возвраты, отчёты, сотрудники, настройки, журнал действий.

Изменения (новая продажа, товар, приёмка, корректировка) применяются к данным внутри приложения и видны во всех разделах до закрытия процесса. После полного закрытия приложения данные возвращаются к исходному демонстрационному набору.

## Ограничения

- Нет связи с сервером и другими устройствами: это витрина, а не учёт.
- Данные не сохраняются между запусками.
- Экспорт CSV отключён, фотографии товаров отсутствуют.
- Установка паролей, ролей и прав не проверяется — интерфейс всегда работает как владелец.

## Пересборка

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-demo.ps1
cd mobile-demo
node .\node_modules\@capacitor\cli\bin\capacitor sync android
$env:JAVA_HOME = "$env:LOCALAPPDATA\StockroomKids\toolchain\jdk17"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\StockroomKids\toolchain\android-sdk"
.\android\gradlew.bat -p android assembleRelease
```

APK подписывается тем же ключом, что и рабочее приложение (`mobile/keystore/srk-release.jks`), поэтому обновления демо ставятся поверх без удаления.
